# 🍜 吃饭转盘（meal-wheel）

> 今天吃什么？转动转盘，让命运替你决定！

一个纯前端、零依赖的「吃什么」转盘小工具，分 **早饭 / 午饭 / 晚饭** 三个独立转盘，每餐菜单可自由增删改，修改自动保存在浏览器本地。

**🌐 在线体验：[https://heyueeee.github.io/chifan/](https://heyueeee.github.io/chifan/)**

---

## ✨ 功能特性

| 功能 | 说明 |
| --- | --- |
| 🌅 三餐独立转盘 | 早饭、午饭、晚饭各有一套转盘和菜单，切换标签页互不影响 |
| 🎡 转盘抽奖 | 点击「开始抽取」，转盘先快后慢旋转 4 秒以上，随机停在某个选项上 |
| 🎉 结果弹窗 | 弹出结果卡片，支持「再抽一次」或「就吃它！」 |
| ✏️ 菜单自由编辑 | 点击文字直接修改、点 × 删除、输入框添加新菜名（回车即可） |
| 💾 自动保存 | 所有修改实时存入浏览器 `localStorage`，刷新/关闭后依然保留 |
| ♻️ 恢复默认 | 一键还原该餐别的默认菜单 |
| 📱 移动端适配 | 手机竖屏、平板、桌面均自适应显示 |

## 🚀 使用方式

### 在线使用

直接打开：**https://heyueeee.github.io/chifan/**

手机浏览器打开后，可「添加到主屏幕」，像 App 一样使用。

### 本地运行

无需安装任何依赖，双击 `index.html` 即可在浏览器中打开使用。

或者用任意静态服务器托管：

```bash
# Python 3
python -m http.server 8080

# Node.js（npx）
npx serve .
```

然后访问 `http://localhost:8080`。

## 📖 使用说明

1. **选择餐别**：顶部切换 🌅 早饭 / ☀️ 午饭 / 🌙 晚饭
2. **定制菜单**：右侧面板中
   - 直接点击列表项文字即可修改
   - 点击 `×` 删除不想要的选项
   - 在输入框中输入菜名，回车或点「添加」新增选项
   - 点「↺ 恢复默认」还原初始菜单
3. **开始抽取**：点击转盘中间的「开始抽取」按钮
4. **看结果**：转盘停止后弹出推荐结果，不满意可以「再抽一次」

> 💡 每个用户修改的菜单只保存在自己的浏览器里，互不影响，也不会上传到服务器。

## 🛠 技术栈

- **HTML5 + 原生 JavaScript**：无框架、无构建、零依赖
- **Canvas 2D**：转盘扇形绘制、文字沿半径排布
- **requestAnimationFrame + easeOutQuart**：平滑的先快后慢抽奖动画
- **localStorage**：按餐别分别持久化菜单数据（key 前缀 `mealWheel.`）

## ⚙️ 自定义技巧

- **改默认菜单**：编辑 `index.html` 中的 `DEFAULT_FOODS` 常量即可修改三套餐别的初始选项
- **改配色**：编辑 `index.html` 中的 `COLORS` 数组调整转盘扇区颜色
- **改背景**：修改 `body` 的 `background` 渐变样式
